# Docker Folders 插件（简体中文版）安装说明

> ⭐ **最简单安装（推荐，需 Unraid 能联网访问 GitHub）**：
> Unraid 网页 → **插件 / Plugins** → **安装插件 / Install Plugin**，地址框粘贴：
> ```
> https://raw.githubusercontent.com/bcfxclub/unraid-docker-folders-zh/main/unraid-docker-folders-modern.plg
> ```
> 点安装即可。Unraid 会自动从同一 `raw.githubusercontent.com` **直链**下载 `.txz`
> （**无重定向，busybox wget 可直接下载**）并完成安装。**无需本地 HTTP 服务、无需 Python。**

> 适用 Unraid 7.x（已验证 7.3.2）。本插件前端 Vue 界面 + 后端 4 个设置页均已汉化为简体中文。
> 打包版本：`2026.10.30.1`（纯数字，符合 Unraid 版本约定），MD5：`1641bfeb52e09ea42e2bb2ba41df6e7a`

## 已汉化范围

- **后端设置页（4 个 `.page` 文件）**：`DockerFolders.page`（设置页）、`Folders.page`、`DockerFoldersDashboard.page`（仪表盘磁贴）、`DockerFoldersInject.page`（原生 Docker 页注入）。

## ⚠️ 之前几次装不上的根因（及本次修复）

- **根因**：最早 `.plg` 里 `.txz` 的下载地址用的是 GitHub **Release** 的
  `github.com/.../releases/download/...` 链接。GitHub 对该链接会先返回
  **302 重定向**到 `objects.githubusercontent.com`，而 Unraid 的 `installplg`
  使用 `busybox wget`，**默认不跟随重定向**，于是下载到的是错误页、报
  `download failure: Invalid URL / Server error response`。（`.plg` 本身能下载成功，
  是因为它走的是 `raw.githubusercontent.com` 直链、无重定向——这正是排查线索。）
- **修复**：把 `.txz` 的下载地址**改为与 `.plg` 相同来源的 `raw.githubusercontent.com` 直链**
  （即仓库根目录的 `.txz` 文件），同样是 200 直链、无重定向，`busybox wget` 可正常下载。
- 同时按 Unraid 社区插件规范，把版本号从带字母的 `2026.10.30-zh1` **规范化为纯数字 `2026.10.30.1`**
  （Unraid 约定 `YYYY.MM.DD.N`，字母版本号会导致更新检查/版本比较异常）。

## 方法一：GitHub 直装（推荐，最简单）

按顶部说明操作即可：

1. Unraid 网页 → **插件 / Plugins** → **安装插件 / Install Plugin**
2. 粘贴 `https://raw.githubusercontent.com/bcfxclub/unraid-docker-folders-zh/main/unraid-docker-folders-modern.plg`
3. 点安装，等待出现 `unraid-docker-folders-modern v2026.10.30.1 installed successfully!`
4. 刷新 Unraid 网页（Ctrl+F5），进入 **Docker → Folders** 或 **设置 → 实用工具 → Docker Folders** 查看中文界面。

> 前提：Unraid 能访问 `github.com` / `raw.githubusercontent.com`（绝大多数家庭/机房网络均可）。

## 方法二：离线安装（Unraid 无法联网 GitHub 时使用）

### 方案 A：installpkg 直接装（最可靠，无需 HTTP 服务）

1. 把 `unraid-docker-folders-modern-2026.10.30.1.txz` 传到 Unraid，例如放入
   `/boot/config/plugins/unraid-docker-folders-modern/`
   （可用 Windows 文件管理器打开 `\\你的UnraidIP\flash` 网络共享拖入）。
2. SSH 进 Unraid，执行：
   ```bash
   installpkg /boot/config/plugins/unraid-docker-folders-modern/unraid-docker-folders-modern-2026.10.30.1.txz
   ```
3. 补跑安装脚本的初始化（创建目录、迁移数据库、设权限）：
   ```bash
   PLUGIN_DIR=/usr/local/emhttp/plugins/unraid-docker-folders-modern
   CONFIG_DIR=/boot/config/plugins/unraid-docker-folders-modern
   mkdir -p "$CONFIG_DIR/backups" "$CONFIG_DIR/data"
   php "$PLUGIN_DIR/scripts/migrate.php"
   find "$PLUGIN_DIR" -type d -exec chmod 755 {} \;
   find "$PLUGIN_DIR" -type f \( -name "*.page" -o -name "*.php" -o -name "*.sql" -o -name "*.html" -o -name "*.js" -o -name "*.css" \) -exec chmod 644 {} \;
   chmod 755 "$PLUGIN_DIR/scripts/"*.php "$PLUGIN_DIR/scripts/"*.sh
   [ -d "$PLUGIN_DIR/event" ] && chmod 755 "$PLUGIN_DIR/event/"*
   php "$PLUGIN_DIR/scripts/restore-cron.php"
   ```
   （`migrate.php` 会初始化 SQLite 数据库，全新安装无旧库也能正常跑。）
4. 刷新 Unraid 网页（Ctrl+F5）即可使用。

### 方案 B：本地 HTTP 服务走标准 plugin install（可选）

若你希望走标准插件安装流程（自动跑全部脚本），可在 Unraid 上用自带 `busybox httpd`
起服务，但需先把 `.plg` 里的下载地址改为 `http://localhost:8000/...txz`，相对麻烦，
一般选方案 A 即可。

## 常见问题

- **之前装过失败版本？** 先清理再重装：
  ```bash
  plugin remove unraid-docker-folders-modern
  ```
  然后按方法一或方法二重新安装。
- **Unraid 提示「有更新」？** 本插件 `.plg` 的 `pluginURL` 已指向本仓库
 （`bcfxclub/unraid-docker-folders-zh`）的 raw `.plg`，版本号与本包一致，
  **不会误提示英文原版更新**，可放心。
- **装完界面还是英文？** 强制刷新（Ctrl+F5）；仍不行可硬重启 Unraid 网页服务或整机重启。
- **`<CHANGES>` 版本历史是英文**——历史更新日志，仅顶部加中文简介，不影响使用。
- **后端模式**：默认 PHP 后端（原默认）。GraphQL 后端与语言无关且默认不启用，未重新打包。

## 安装后位置

- 插件文件：`/usr/local/emhttp/plugins/unraid-docker-folders-modern/`
- 配置/数据库：`/boot/config/plugins/unraid-docker-folders-modern/`
- 入口：**Docker → Folders**，或 **设置 → 实用工具 → Docker Folders**
