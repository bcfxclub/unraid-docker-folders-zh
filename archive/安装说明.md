## ⚠️ 为什么之前两次都装不上

- **第一次**（`Invalid URL / Server error`）：下载地址写成 `http://localhost:8000/...`，
  需要在 Unraid 本机起 HTTP 服务。但你跑 `python3 -m http.server` 时 Unraid 报
  `python3: command not found`（Unraid 默认没装 Python），服务没起来 → 下载失败。
- **第二次**（`download failure: Generic error`）：改成裸本地路径后，Unraid 的 `installplg`
  下载器**只可靠支持 `http(s)://`**，裸路径会被当成坏 URL → 失败。

**解决办法：用 Unraid 自带的 `busybox httpd` 起本地服务（不需要 Python），下载地址走 `http://localhost`。**

## 方法一：本地 HTTP 服务（推荐，自动化最完整）

### 第 1 步：把两个文件传到 Unraid

**方式 A（Windows 文件管理器，最简单）**
1. 打开 `\\你的UnraidIP\flash`（如 `\\192.168.1.100\flash`），用 root 登录。
2. 进入 `flash/config/plugins/`，新建文件夹 `unraid-docker-folders-modern`。
3. 把 `unraid-docker-folders-modern-2026.10.30-zh1.txz` 放进这个文件夹。
4. 把 `unraid-docker-folders-modern.plg` 放进 `flash/config/plugins/` **根目录**（不要进子文件夹）。

**方式 B（命令行 scp，Windows 10+ 自带 OpenSSH）**
```bat
ssh root@你的UnraidIP "mkdir -p /boot/config/plugins/unraid-docker-folders-modern"

scp unraid-docker-folders-modern-2026.10.30-zh1.txz root@你的UnraidIP:/boot/config/plugins/unraid-docker-folders-modern/

scp unraid-docker-folders-modern.plg root@你的UnraidIP:/boot/config/plugins/
```

### 第 2 步：在 Unraid 终端起临时 HTTP 服务（无需 Python）

```bash
cd /boot/config/plugins
nohup busybox httpd -p 8000 -h /boot/config/plugins &
```
> 若 8000 被占用，把 `8000` 换成别的（如 `8088`），并相应修改下面的 `8000`。

### 第 3 步：自测文件是否可达（很重要，能提前发现“文件没传对”）

```bash
wget -qO- http://localhost:8000/unraid-docker-folders-modern.plg | head -3
```
能看到 `<PLUGIN ...>` 之类的 XML 即正常。再确认 txz 在盘上：
```bash
ls -la /boot/config/plugins/unraid-docker-folders-modern/unraid-docker-folders-modern-2026.10.30-zh1.txz
```

### 第 4 步：安装

**在 Unraid 终端执行（最简单）：**
```bash
plugin install http://localhost:8000/unraid-docker-folders-modern.plg
```
> 或在 Unraid 网页 → **插件 / Plugins → 安装插件 / Install Plugin**，地址框粘贴
> `http://localhost:8000/unraid-docker-folders-modern.plg`。

看到 `unraid-docker-folders-modern v2026.10.30-zh1 installed successfully!` 即成功。

### 第 5 步：关闭临时 HTTP 服务

```bash
pkill -f "busybox httpd"
```

### 第 6 步：刷新网页

刷新 Unraid 网页（建议 Ctrl+F5 强制刷新），进入以下位置查看中文界面：
- **Docker → Folders**
- **设置 / Settings → 实用工具 / Utilities → Docker Folders**

## 方法二：完全不用 HTTP 服务（installpkg 兜底）

若方法一的 HTTP 服务在某台机器上仍有问题，可手动安装（txz 仍须先传到 Unraid）。

**第 1 步：** 同方法一第 1 步，把 `unraid-docker-folders-modern-2026.10.30-zh1.txz`
放到 `/boot/config/plugins/unraid-docker-folders-modern/`。

**第 2 步：** 在 Unraid 终端直接安装 txz（解包到系统目录）：
```bash
installpkg /boot/config/plugins/unraid-docker-folders-modern/unraid-docker-folders-modern-2026.10.30-zh1.txz
```

**第 3 步：** 手动补跑安装脚本里的初始化（创建目录、迁移数据库、设权限）：
```bash
PLUGIN_DIR=/usr/local/emhttp/plugins/unraid-docker-folders-modern
CONFIG_DIR=/boot/config/plugins/unraid-docker-folders-modern

mkdir -p "$CONFIG_DIR/backups" "$CONFIG_DIR/data"
php "$PLUGIN_DIR/scripts/migrate.php"
find "$PLUGIN_DIR" -type d -exec chmod 755 {} \;
find "$PLUGIN_DIR" -type f \( -name "*.page" -o -name "*.php" -o -name "*.sql" -o -name "*.html" -o -name "*.js" -o -name "*.css" \) -exec chmod 644 {} \;
chmod 755 "$PLUGIN_DIR/scripts/"*.php "$PLUGIN_DIR/scripts/"*.sh
[ -d "$PLUGIN_DIR/event" ] && chmod 755 "$PLUGIN_DIR/event/"*
/usr/bin/php "$PLUGIN_DIR/scripts/restore-cron.php"
```
（`migrate.php` 会初始化 SQLite 数据库，全新安装无旧库也能正常跑。）

**第 4 步：** 刷新 Unraid 网页即可使用。

## 常见问题

- **之前装过失败版本？** 先清理再重装：
  ```bash
  plugin remove unraid-docker-folders-modern
  ```
  然后按方法一或二重新安装。
- **Unraid 提示「有更新」？** 本插件 `.plg` 的 `pluginURL` 仍指向原版上游，Unraid 可能提示英文原版更新——
  那会**覆盖中文**，请忽略；需要时再用本中文包重装恢复。
- **装完界面还是英文？** 强制刷新（Ctrl+F5）；若仍不行，重启 Unraid 网页服务或硬重启。
- **`<CHANGES>` 版本历史是英文**——那是历史更新日志，仅顶部加了中文简介，不影响使用。
- **后端模式**：本包默认 PHP 后端（原始默认）。GraphQL 后端与界面语言无关且默认不启用，未重新打包。
